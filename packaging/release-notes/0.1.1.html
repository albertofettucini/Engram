Engram 0.1.1

  • Fixed: engram-mcp --connect could write a path that didn't exist, or one the next brew upgrade would delete. It now writes the stable Homebrew path and refuses to write a broken one.
  • --connect now sets up Claude Code too.
  • New: engram-mcp --doctor checks your setup and tells you how to fix anything that's off.
  • Memories now record which app wrote them.
  • New: Ask mode in the search bar. Ask in plain words, and Engram finds the closest memories.
  • Forget conversation now moves the file to the Trash.
  • Imports and pastes default to Everything and tell you how many memories came in.
  • Settings shows where your memory files live, with Reveal in Finder.
