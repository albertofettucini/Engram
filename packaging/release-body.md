Engram VERSION: one shared, local memory for your AIs.

**Install**
- Homebrew (MCP server): `brew install albertofettucini/engram/engram`, then `engram-mcp --connect` (Claude Desktop + Claude Code) and `engram-mcp --doctor` to check.
- Or download `Engram-VERSION.zip` below, unzip, and drag it to Applications. The app isn't notarized, so open it once, then go to System Settings → Privacy & Security and click Open Anyway.

The CLI binaries are universal (Apple Silicon + Intel). What changed: see the in-app update notes or the README.
